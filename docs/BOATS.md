# Teaching it a boat dock

Back to the [README](../README.md)

The game does not tell addons where the docks are. Until a dock is known, the arrow heads for the port town's flight
master (by the harbour) and says so. To teach it the real spot, once:

1. Walk to the dock and **stand on it**, at the spot where you board.
2. Type `/lazy boat mark <port>`, for example `/lazy boat mark menethil`. (Or use **Mark this dock** in the minimap menu
   or at the boat NPC.)
3. `/lazy boat <where>` now points at it. `/lazy boat list` shows the docks you taught.

Ports: stormwind, auberdine, rutheran (Teldrassil), menethil, theramore, southshore, ratchet, bootybay, gromgol,
orgrimmar, undercity, steamwheedle, powderfuse.

If you taught a dock, please post the line from `/lazy boat list` as an [Issue](../../../issues) or in
[Discussions](../../../discussions) so it can be built in for everyone.
